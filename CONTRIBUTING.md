# Contributing

Thank you for considering contributing to this repository.

## Getting Started

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Commit your work with descriptive messages.
5. Push your branch.
6. Open a Pull Request.

## Coding Guidelines

* Keep workflows simple and reusable.
* Use official GitHub Actions whenever possible.
* Pin action versions to major releases.
* Validate YAML syntax before submitting.

## Reporting Issues

If you find a bug or have a suggestion, please open an issue using the appropriate issue template.
